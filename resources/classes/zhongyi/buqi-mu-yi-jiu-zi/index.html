Unit 86: Treating the Mother to Rescue the Child

An early lesson in this unit described the generating cycle, in which each element feeds and produces the next, and often gets described using a family metaphor: the producing element as "mother," the produced element as "child." That metaphor isn't just decorative — it's the basis for a specific clinical principle: "when the child is deficient, treat the mother," meaning that a weakness in one element can sometimes be addressed by strengthening the element that feeds it, rather than treating the weak element directly.

這個單元稍早的一課描述過相生的循環，每個元素滋養並生出下一個，而且常常用一個家庭的比喻來描述：生的那一方叫「母」，被生的那一方叫「子」。這個比喻不只是裝飾——它是一個具體臨床原則的基礎：「虛則補其母」，意思是一個元素的虛弱，有時候可以透過強化滋養它的那個元素來處理，而不是直接處理這個虛弱的元素本身。

The logic follows directly from how the generating cycle is supposed to work: if an element is running low, one plausible cause is that its mother element isn't feeding it enough, in which case treating the child alone is treating a downstream symptom while leaving the actual shortfall untouched upstream. Strengthening the mother restores the supply the child depends on, addressing the root of the shortfall rather than only its visible result.

這個邏輯，直接跟著相生循環應該如何運作的道理走：如果一個元素偏低，一個可能的原因，是它的母元素沒有給它足夠的滋養，這種情況下，只處理子元素，等於是在處理下游的症狀，卻放著上游真正的短缺不管。強化母元素，恢復了子元素所依賴的供應，處理的是短缺的根源，而不只是它可見的結果。

This principle is one concrete payoff of a question this course has kept coming back to since the unit's first lesson — why organize organs and functions into five categories connected by cycles at all, rather than just listing them separately. The generating cycle isn't only a way to describe how the five elements relate to each other in theory; it's also a map for figuring out where in the system a given weakness might actually be coming from, and where support might need to be directed instead of where the symptom happens to be showing up.

這個原則，是這門課從這個單元第一課就一直回頭問的一個問題的具體回報——為什麼要把臟腑與功能組織成五個由循環連接起來的類別，而不是各自分開列出來就好。相生循環不只是一種描述五行理論上如何互相關聯的方式；它也是一張地圖，用來找出一個特定的虛弱實際上可能是從系統裡的哪裡來的，以及支援可能需要導向哪裡，而不是只導向症狀剛好出現的那個地方。

Questions · 閱讀理解

According to the passage, what does "when the child is deficient, treat the mother" mean?

That a weakness in one element (the "child") can sometimes be addressed by strengthening the element that feeds it (the "mother"), rather than treating the weak element directly.

According to the passage, what is the logic behind treating the mother element instead of the child directly?

If an element is running low, one cause may be that its mother element isn't feeding it enough; treating the child alone leaves the actual shortfall upstream untouched, while strengthening the mother restores the supply.

According to the last paragraph, what does the generating cycle serve as, beyond describing theoretical relationships?

A map for figuring out where in the system a weakness might actually be coming from, and where support might need to be directed, rather than only where the symptom shows up.
