Big idea · 一句話看懂

To keep a message secret, a computer scrambles it by a rule, using a secret number called a key. Anyone on the way can see the scrambled message but cannot understand it. Only someone with the right key can turn it back. The rule itself can be known to everyone. The lock is safe only if there are far too many keys to try.
要讓一則訊息保密，電腦會照一個規則把它打亂，打亂時用到一個祕密的數，叫做金鑰。路上的任何人都看得到被打亂的訊息，卻看不懂。只有拿著正確金鑰的人，才能把它變回來。規則本身可以讓所有人知道。要金鑰多到試不完，這把鎖才安全。

A teaching model. The lock here is the letter-shift cipher that Julius Caesar used about two thousand years ago. It is easy to follow, and it is far too weak for real use: it has only 25 keys. Real encryption does not shift letters. It works on the bits of the message, with keys that are very long numbers. Real computers also do not need to meet in advance to agree on a key; a method called public-key cryptography lets them do that across the network. What is the same is the idea: a public rule, a secret key, and a watcher who sees only nonsense.
這是教學用的示意模型。這裡的鎖是大約兩千年前凱撒用過的字母位移。它很容易看懂，但實際使用遠遠不夠強：金鑰只有 25 把。真的加密不是移字母，而是對訊息的位元動手，用的金鑰是很長的數。真的電腦也不必事先見面約好金鑰；有一種叫公開金鑰密碼學的方法，讓它們隔著網路就能約好。相同的是這個道理：規則公開、金鑰保密，偷看的人只看到一串沒有意義的東西。

Unit 14: How Does a Computer Keep a Secret?

In Lesson 13 you saw that a message does not go straight from your computer to the other one. It passes through many machines on the way, and you do not control any of them. Anyone who runs one of those machines could look at what goes by. So how can you send something private? The answer is very old. It is called cryptography: writing a message so that only the person it is meant for can understand it.

第十三課說過，訊息不是從你的電腦直接到另一台電腦。它在路上會經過很多台機器，而那些機器沒有一台歸你管。管那些機器的任何人，都可以看一看經過的東西。那要怎麼送出不想讓別人看到的東西？答案非常古老，叫做密碼學（cryptography）：把訊息寫成只有該收到的人才看得懂的樣子。

Here is one way, used by Julius Caesar. Move every letter three places along the alphabet: A becomes D, B becomes E, and so on. “MEET ME AT NOON” turns into “PHHW PH DW QRRQ.” Scrambling a message like this is called encryption. There are two parts to it. The rule is “move each letter along.” The key is the number that says how far: here, 3.

這裡有一個方法，是凱撒用過的。把每個字母在字母表上往後移三格：A 變成 D，B 變成 E，依此類推。「MEET ME AT NOON」就變成「PHHW PH DW QRRQ」。像這樣把訊息打亂，叫做加密（encryption）。它有兩個部分。規則是「把每個字母往後移」。金鑰（key）是說明要移幾格的那個數：這裡是 3。

Your friend knows the key, so your friend moves every letter back three places and reads the message. That is decryption. The watcher in the middle sees the same letters, but without the key they mean nothing. Notice what has to be secret. It is not the rule. Everyone can know the rule. Only the key must be kept between the two of you, and you must both have exactly the same one.

你的朋友知道金鑰，所以把每個字母往回移三格，就讀到訊息了。這叫解密（decryption）。中間偷看的人看到的是同樣那些字母，可是沒有金鑰，它們毫無意義。注意到底是什麼要保密。不是規則——規則誰都可以知道。只有金鑰必須留在你們兩人之間，而且兩個人拿的必須一模一樣。

Caesar’s lock has a weakness. There are only 25 possible keys. A watcher can simply try them all, one after another, until the message makes sense. So the safety of a lock depends on how many keys there are. A computer’s key is a number written in bits, and you saw in Lesson 1 that every extra bit doubles the count. A standard method used today has keys of 128, 192, or 256 bits. A key of 128 bits can be any one of a number of keys that is 39 digits long.

凱撒的鎖有一個弱點：金鑰只有 25 種可能。偷看的人只要一把一把全部試過，試到訊息讀得通為止。所以一把鎖安不安全，要看金鑰有幾把。電腦的金鑰是用位元寫成的數，而第一課說過，每多一個位元，數目就加倍。今天有一種標準的加密方法，金鑰是 128、192 或 256 個位元。128 個位元的金鑰，可能的數目是一個 39 位數。

One puzzle remains. How can two computers that have never met agree on a key, when the watcher hears everything they say? In 1976, two researchers, Whitfield Diffie and Martin Hellman, described a way. Each side has two keys. One is published for everyone to use for locking. The other is kept secret and is the only one that unlocks. Anyone can send you a locked message, and only you can open it.

還剩下一個難題。兩台從來沒見過面的電腦，要怎麼約好一把金鑰？它們說的每一句話，偷看的人都聽得到。1976 年，兩位研究者迪菲（Whitfield Diffie）和赫爾曼（Martin Hellman）提出了一個辦法。每一方都有兩把金鑰。一把公開，讓所有人用來上鎖；另一把自己留著，只有它能開鎖。任何人都可以送一則上了鎖的訊息給你，而只有你打得開。

You use all this every day. When a web address begins with https, the browser and the server are encrypting everything they send to each other. The machines in between see only scrambled data. But remember what encryption does and does not do. It keeps the message private on the way. It cannot tell you whether the person at the other end is honest, and it cannot help if you give your password to the wrong person.

這些東西你每天都在用。網址開頭是 https 的時候，瀏覽器和伺服器會把它們互相傳送的一切都加密。中途的機器只看得到打亂的資料。不過要記得加密能做什麼、不能做什麼。它讓訊息在路上不被別人看懂。它沒辦法告訴你另一頭的人是不是誠實，而如果你把密碼交給了不該給的人，它也幫不上忙。

Questions · 閱讀理解

In Caesar’s cipher, what is the rule and what is the key? Which one must be kept secret?

The rule is to move every letter along the alphabet. The key is the number that says how many places. The rule can be known to everyone; only the key must be secret.

Why is a cipher with only 25 keys not safe?

Someone who catches the message can try all 25 keys one after another until the message makes sense. A lock is safe only when there are far too many keys to try.

What does https at the start of a web address tell you, and what does it not tell you?

It tells you that the browser and the server encrypt what they send to each other, so the machines in between cannot read it. It does not tell you whether the one at the other end is honest.

    Stories Behind Secret Writing · 祕密書寫的故事

    Caesar’s three places, a cipher that undoes itself, a lock anyone can close, and a number with 39 digits 凱撒的三格、會自己解開的加密、誰都能鎖上的鎖、一個 39 位數

    Four short stories about keeping messages private.
    關於「不讓別人看懂訊息」的四個小故事。

    Caesar · 凱撒

    Three places down the alphabet在字母表上往後三格

    According to Britannica, the Roman writer Suetonius describes the cipher that Julius Caesar used in his letters: he replaced each letter with the letter three places down in the alphabet, and for letters at the end, the cipher went back around to the start. Caesar’s successor, Augustus, found this too complicated and replaced each letter with the one right after it. The method is still named after Caesar.
    根據大英百科，羅馬作家蘇埃托尼烏斯（Suetonius）記下了凱撒寫信時用的加密方法：把每個字母換成字母表上往後第三個字母，到了字母表的尾巴就繞回開頭。凱撒的繼承人奧古斯都覺得這樣太複雜，改成把每個字母換成緊接著的下一個。這個方法至今仍以凱撒為名。

    ROT13

    A cipher that undoes itself會自己解開的加密

    There are 26 letters, and 13 is half of 26. So if you shift a message by 13 and then shift it by 13 again, every letter has gone all the way around and is back where it began. Britannica notes that this cipher, called ROT13, has been widely used to protect text against being read by accident, and that it was chosen because applying it twice returns the original. CODE becomes PBQR, and PBQR becomes CODE.
    英文字母有 26 個，13 剛好是 26 的一半。所以把一則訊息移 13 格，再移 13 格，每個字母都繞了一整圈，回到原來的位置。大英百科提到，這種叫 ROT13 的加密一直被廣泛用來避免文字被不小心讀到；選 13，就是因為做兩次會回到原文。CODE 變成 PBQR，PBQR 又變回 CODE。

    1976

    A lock anyone can close誰都能鎖上的鎖

    With a cipher like Caesar’s, the two sides must somehow share one key, and a key that is sent can be caught on the way. Britannica calls what happened in 1976 one of the most inspired insights in the history of the subject: Whitfield Diffie and Martin Hellman proposed that each user keep a decryption key secret and publish an encryption key in a public directory. It was the first discussion of the idea in the open literature. Later it was revealed that James Ellis, Clifford Cocks, and Malcolm Williamson at Britain’s GCHQ had discovered it earlier, in secret.
    用凱撒那樣的加密，兩邊得想辦法拿到同一把金鑰，而送出去的金鑰可能在路上被攔走。大英百科把 1976 年發生的事稱為這門學問史上最有靈感的洞見之一：迪菲和赫爾曼提出，每個使用者把解密的金鑰自己留著，把加密的金鑰放在一份公開的名錄裡。這是公開文獻中第一次討論這個想法。後來才揭露，英國政府通訊總部（GCHQ）的艾利斯（James Ellis）、考克斯（Clifford Cocks）和威廉森（Malcolm Williamson）更早就祕密地發現了它。

    128 bits · 128 個位元

    A number with 39 digits一個 39 位數

    The United States standard called AES says its keys are 128, 192, or 256 bits long. The rest of this card is our own arithmetic. Caesar’s cipher has 25 keys, fewer than 5 bits would give. A key of 128 bits can be any of 340,282,366,920,938,463,463,374,607,431,768,211,456 keys. Each extra bit doubles the number, exactly as each extra switch did in Lesson 1. Trying keys one by one is the slow search from Lesson 10, and a good lock is designed so that there is no quicker way.
    美國一套叫 AES 的標準寫明，它的金鑰長度是 128、192 或 256 個位元。這張卡接下來的部分是我們自己算的。凱撒的加密有 25 把金鑰，比 5 個位元的還少。128 個位元的金鑰，可能的數目是 340,282,366,920,938,463,463,374,607,431,768,211,456 把。每多一個位元，數目就加倍，和第一課每多一個開關一樣。一把一把試金鑰，就是第十課那種慢的找法；好的鎖在設計上，就是要讓人找不到更快的方法。

    Myth vs. Fact · 常見迷思

    Four things people get wrong 四個常見的誤會

    ✗ Myth · 迷思If nobody can see my screen, nobody can see my message.只要沒人看到我的螢幕，就沒人看得到我的訊息。

    ✓ Fact · 事實A message passes through many machines between you and the other person. Without encryption, whoever runs them could read it.訊息在你和對方之間會經過很多台機器。沒有加密的話，管那些機器的人就讀得到。

    ✗ Myth · 迷思A code is safe as long as nobody knows how it works.只要沒人知道密碼是怎麼運作的，它就安全。

    ✓ Fact · 事實Everyone knows how Caesar’s cipher works. Safety has to come from the key, and from there being too many keys to try.凱撒的加密方法人人都知道。安全必須來自金鑰，而且金鑰要多到試不完。

    ✗ Myth · 迷思Once a message is encrypted, it cannot be read by anyone else.訊息一旦加密，別人就一定讀不到。

    ✓ Fact · 事實It depends on the lock. With only 25 keys, a brute-force attack tries them all. Britannica notes that Caesar’s cipher can be broken in other ways too.要看是什麼鎖。金鑰只有 25 把的話，暴力破解把它們全部試一遍就行了。大英百科指出，凱撒的加密還有別的破解方法。

    ✗ Myth · 迷思If the address starts with https, the site can be trusted.網址開頭是 https，這個網站就可以信任。

    ✓ Fact · 事實The letters mean that what travels between you and the server is encrypted. They say nothing about who runs the server or whether what it tells you is true.這幾個字母的意思是：你和伺服器之間傳的東西有加密。它們並沒有說那台伺服器是誰在管，也沒有說它告訴你的事是不是真的。

    Remember It · 記憶口訣

    A secret in a sentence 一句話記住保密

    Public rule, secret key規則公開，金鑰保密

    Everyone may know the method. Nobody else may know the key.
    方法誰都可以知道；金鑰不能讓別人知道。

    Same key at both ends兩邊同一把金鑰

    Off by one, and it is nonsense.
    差一，就是一堆亂碼。

    Few keys, weak lock金鑰少，鎖就弱

    25 keys can all be tried.
    25 把，全部試得完。

    One more bit, twice the keys多一個位元，金鑰多一倍

    That is why real keys are long.
    所以真的金鑰很長。

    Before You Start · 動手之前

    A few reminders 幾個提醒

    • Do not use a letter-shift cipher for anything that really must stay secret. It is a way to learn the idea, not a way to protect yourself.真正必須保密的東西，不要用字母位移來保護。它是用來學道理的，不是用來保護自己的。
    • Never write a real password in a classroom game, on a note, or in a tool on a web page.真正的密碼，絕對不要寫在課堂遊戲裡、紙條上，或網頁上的任何小工具裡。
    • Being “the watcher” is a game with made-up messages. Reading other people’s real messages without permission is wrong, and it may be against the law.「偷看的人」只是用編出來的訊息玩的遊戲。沒有得到同意就去看別人真正的訊息是不對的，也可能違法。
    • Use a school or family computer only with permission.用學校或家裡的電腦要先得到同意。

    Classroom Activity 1 · 課堂活動一

    Pass the Note 傳紙條

    You need · 準備材料

    • Two paper strips for each student, each with the alphabet written along it in evenly spaced letters每人兩條紙條，上面各寫一排間隔相同的字母表
    • Small slips of paper for messages寫訊息用的小紙片
    • A row of five or six students to be “the network”五、六位同學排成一排，當作「網路」

    Steps · 步驟

    1. Two students at opposite ends of the row agree on a key in a whisper. To use it, slide one alphabet strip along the other by that many letters.坐在那一排兩端的兩位同學，小聲約好一把金鑰。使用的方法：把一條字母表沿著另一條滑過那麼多格。
    2. The sender writes a short English message, encrypts it with the strips, and passes the slip along the row.送訊息的同學寫一句短短的英文，用紙條把它加密，再把紙片沿著那一排傳過去。
    3. One student in the middle is the watcher and may copy the slip before passing it on. The receiver decrypts it and reads it aloud.中間有一位同學是偷看的人，可以先把紙片抄下來再往下傳。收訊息的同學把它解密，大聲唸出來。
    4. Now give the watcher two minutes and a pair of strips. Can the watcher find the key by trying them one by one?接著給偷看的人兩分鐘和一組紙條。他能不能一把一把試，把金鑰找出來？

    Talk about the whisper. How did the two ends agree on the key without the watcher hearing? In a real network there is no whisper, which is the puzzle that public-key cryptography solved. In Taiwan’s junior high Information Technology curriculum, this lesson matches the topic “Information technology and human society”: 資 H-IV-1, protecting personal data, and 資 H-IV-3, information security.
    和學生談談那句「小聲約好」。兩端是怎麼不讓偷看的人聽到就約好金鑰的？真的網路上沒有辦法小聲說，這正是公開金鑰密碼學解決的難題。對照十二年國教國中「資訊科技」的學習內容，這一課對應「資訊科技與人類社會」主題：資 H-IV-1 個人資料保護、資 H-IV-3 資訊安全。

    Classroom Activity 2 · 課堂活動二

    Check It on Your Own Computer 在自己的電腦上驗證

    You need · 準備材料

    • A computer or phone with a web browser一台有瀏覽器的電腦或手機
    • The “Lock and Unlock a Message” tool on this page這一頁的「自己加密、解密」小工具
    • Paper and a pencil紙和鉛筆

    Steps · 步驟

    1. Look at the address of this page. Does it begin with https? Write down the first five letters.看看這一頁的網址。開頭是 https 嗎？把前五個字母寫下來。
    2. Visit three other sites you use for school. Write down whether each address begins with https.再看三個你上課會用到的網站。把每個網址的開頭是不是 https 記下來。
    3. In the tool, lock the word CODE with the key 13. Then lock the result with 13 again. What do you get?在小工具裡，用金鑰 13 把 CODE 這個字加密。再把結果用 13 加密一次。你得到什麼？
    4. Lock your own first name with a key of your choice. Give the result to a partner and see how long it takes them to break it.用你自己選的金鑰把你的名字（英文）加密，把結果交給同伴，看他多久能破解。

    CODE becomes PBQR, and PBQR becomes CODE again. On a phone the address may be partly hidden; tap the address bar to see all of it. An address beginning with https means the connection is encrypted. It is not a promise about the site itself.
    CODE 會變成 PBQR，PBQR 又變回 CODE。手機上的網址可能只顯示一部分，點一下網址列就看得到完整的。網址開頭是 https，表示連線有加密；它並不是對這個網站本身的保證。
