Big idea · 一句話看懂

Bits can only make numbers. To turn numbers into words, pictures, and sound, people agree on codes: tables that say which number stands for which letter, which color, or how high a sound wave is. The same bits mean different things under different codes.
位元只能組成數。要把數變成文字、圖片和聲音，靠的是大家約好的「編碼」：一張對照表，規定哪個數代表哪個字、哪個顏色，或聲波有多高。同樣的位元，照不同的表來讀，意思就不一樣。

Unit 2: How Do 0s and 1s Become Words, Pictures, and Sound?

In Lesson 1, a row of switches could show a number, and nothing else. But a computer shows you words and photos, and it plays music. How can numbers do all that? The answer is an agreement. People decide that a certain number will stand for a certain thing, and they write the agreement down in a table. Such a table is called a code. Once everyone uses the same code, any computer can turn numbers back into the same letters, colors, and sounds.

在第一課，一排開關能表示一個數，也只能表示一個數。可是電腦會顯示文字和照片，還會播放音樂。數怎麼做得到這些事？答案是「約定」。人們決定某個數代表某樣東西，並且把這個約定寫成一張表。這樣的表叫做「編碼」。只要大家都用同一套編碼，任何一台電腦都能把數變回同樣的字、顏色和聲音。

Start with letters. In 1963, American computer makers agreed on a code called ASCII. It uses seven bits, so it has room for 128 characters: the English letters, the digits, punctuation marks, and a few signals for machines. In ASCII, the capital letter A is number 65, B is 66, and a lowercase a is 97. When you press A on a keyboard, the computer does not store the shape of the letter. It stores 65, which in bits is 1000001.

先說字。1963 年，美國的電腦廠商約定了一套叫 ASCII 的編碼。它用七個位元，所以容得下 128 個字元：英文字母、數字、標點符號，還有幾個給機器用的訊號。在 ASCII 裡，大寫的 A 是 65 號，B 是 66 號，小寫的 a 是 97 號。你在鍵盤上按 A 的時候，電腦存的不是這個字母的形狀，而是 65，寫成位元就是 1000001。

But 128 characters are not enough for the world. For years, different places made their own codes, and the same number could mean different characters on different computers. Text opened with the wrong code turned into nonsense. Unicode fixes this with one giant table for every writing system. The 2026 version, Unicode 18.0, lists 172,808 characters. The Chinese character 永 is number 27,704, usually written U+6C38. Most web pages store these numbers with a method called UTF-8, which uses one byte for an English letter and three bytes for a common Chinese character such as 永.

可是 128 個字元不夠全世界用。有很多年，不同的地方各自訂了自己的編碼，同一個數在不同的電腦上可能代表不同的字；用錯編碼打開的文字，就變成一堆看不懂的亂碼。Unicode 的解決辦法是：替所有的文字做一張超大的表。2026 年的版本 Unicode 18.0 收了 172,808 個字元。中文的「永」是 27,704 號，通常寫成 U+6C38。大多數的網頁用一種叫 UTF-8 的方法來存這些編號：一個英文字母用一個位元組，像「永」這樣的常用中文字用三個位元組。

Pictures work the same way. A picture on a screen is a grid of tiny squares called pixels, and each pixel has just one color. That color is stored as three numbers: how much red, how much green, and how much blue. Each number usually gets one byte, so it runs from 0 to 255. Red 255, green 0, blue 0 is pure red. Three bytes give 16,777,216 possible colors. A photo 4,000 pixels wide and 3,000 pixels tall has 12 million pixels, so before any shrinking it needs 36 million bytes.

圖片也是同樣的道理。螢幕上的一張圖是由很多小方格排成的，這些小方格叫做「像素」，每個像素只有一種顏色。這個顏色存成三個數：紅有多少、綠有多少、藍有多少。每個數通常用一個位元組，所以是 0 到 255。紅 255、綠 0、藍 0 就是純紅。三個位元組一共可以表示 16,777,216 種顏色。一張寬 4,000 像素、高 3,000 像素的照片有 1,200 萬個像素，還沒縮小之前就需要 3,600 萬個位元組。

Sound becomes numbers, too. A microphone turns sound into an electrical wave that rises and falls. A computer measures the height of that wave again and again, at equal steps of time, and writes down each measurement as a number. This is called sampling. For a music CD, the wave is measured 44,100 times every second, and each measurement is a 16-bit number. To play the music, the computer reads the numbers back in order and a speaker rebuilds the wave.

聲音也會變成數。麥克風把聲音變成一條上上下下的電波。電腦每隔一小段相等的時間，就量一次這條波有多高，把每一次量到的結果記成一個數。這叫做「取樣」。音樂 CD 每一秒要量 44,100 次，每一次記成一個 16 位元的數。要播放音樂時，電腦照順序把這些數讀出來，喇叭再把波重新做出來。

Here is the surprising part: the bits themselves do not say what they are. The eight bits 01000001 can be the number 65, the letter A, or a dim shade of red. Nothing in the bits tells you which. The meaning comes from the code that the computer uses to read them. That is why a photo opened as if it were text looks like nonsense. Everything in a computer is numbers, plus an agreement about what the numbers mean.

最讓人意外的是：位元自己並沒有說它是什麼。01000001 這八個位元，可以是數 65，可以是字母 A，也可以是一種暗暗的紅色。位元裡沒有任何東西告訴你是哪一種。意思來自電腦用哪一套編碼去讀它。所以把一張照片當成文字打開，看到的就是一堆亂碼。電腦裡的一切都是數，再加上一個「這些數代表什麼」的約定。

Questions · 閱讀理解

What is a code, and why does everyone need to use the same one?

A code is a table that says which number stands for which thing, such as a letter. If two computers use different codes, the same numbers turn into different characters, and the text becomes nonsense.

How is the color of one pixel stored?

It is stored as three numbers: how much red, how much green, and how much blue. Each number is usually one byte, from 0 to 255.

The bits 01000001 can mean 65, the letter A, or a shade of red. How does a computer know which one is meant?

The bits do not say. The meaning comes from the code the computer uses to read them: read as a number they are 65, read with ASCII they are A, and read as a color they are an amount of red.

    Stories Behind the Codes · 編碼的故事

    A table from 1963, one table for the world, three bytes of color, and a shiny disc 1963 年的一張表、全世界共用的表、三個位元組的顏色、一張亮亮的光碟

    Four short stories about the agreements behind your screen and speakers.
    螢幕和喇叭背後的四個「約定」。

    1963 · ASCII

    When computers could not talk to each other電腦之間講不通的年代

    Before ASCII, each computer maker represented letters and digits in its own way; IBM alone used nine different character sets. A committee of computer makers worked out a common code, and ASCII was approved as the American standard on June 17, 1963. The name stands for American Standard Code for Information Interchange. With seven bits it has 128 codes: 1010000 is a capital P, and 1110000 is a lowercase p.
    在 ASCII 之前，每家電腦廠商各用各的方法表示字母和數字，光是 IBM 一家就用了九套不同的字元集。電腦廠商組成的委員會訂出一套共同的編碼，1963 年 6 月 17 日，ASCII 獲准成為美國標準。ASCII 是 American Standard Code for Information Interchange（美國資訊交換標準碼）的縮寫。它用七個位元，有 128 個編號：1010000 是大寫的 P，1110000 是小寫的 p。

    Unicode · 萬國碼

    One table for every writing system所有文字共用的一張表

    Unicode gives every character a number of its own, whatever the language. The table keeps growing: version 18.0, released on September 16, 2026, added 13,007 characters for a total of 172,808. The way most web pages store those numbers, UTF-8, was designed by Ken Thompson. His colleague Rob Pike recalled that it happened “on a placemat in a New Jersey diner one night in September or so 1992.”
    不管是哪一種語言，Unicode 都給每個字元一個自己的編號。這張表一直在長大：2026 年 9 月 16 日發布的 18.0 版新增 13,007 個字元，總共 172,808 個。大多數網頁存這些編號的方法 UTF-8，是肯・湯普遜（Ken Thompson）設計的。他的同事羅布・派克（Rob Pike）回憶，那是「1992 年 9 月左右的一個晚上，在紐澤西一家小餐館的餐墊紙上」寫出來的。

    RGB · 三原色光

    Why three numbers are enough為什麼三個數就夠了

    A screen makes colors by adding light. Look at a screen through a magnifying glass and you will see that each pixel is made of three small dots: one gives off red light, one green, and one blue. Red and green light together look yellow, and all three together look white. With one byte for each of the three, there are 256 × 256 × 256 = 16,777,216 possible colors.
    螢幕是用「把光加在一起」的方法做出顏色的。用放大鏡看螢幕，會看到每個像素由三個小點組成：一個發紅光，一個發綠光，一個發藍光。紅光加綠光看起來是黃色，三種光全開看起來是白色。三個小點各用一個位元組，就有 256 × 256 × 256＝16,777,216 種可能的顏色。

    1982 · CD

    Music as a list of numbers音樂變成一串數

    The compact disc was invented together by Philips and Sony and went on sale in 1982. It was how most people first owned music stored as numbers. People can hear sounds up to about 20,000 waves a second, and to catch a wave you must measure it at least twice. So a CD samples a little more than twice that fast: 44,100 times a second.
    CD（光碟）由飛利浦和索尼共同發明，1982 年上市。對大多數人來說，這是第一次擁有「存成數字」的音樂。人最高大約能聽到每秒兩萬個波的聲音，而要抓住一個波，至少得量它兩次。所以 CD 取樣的速度比兩倍再快一點：每秒 44,100 次。

    Myth vs. Fact · 常見迷思

    Four things people get wrong 四個常見的誤會

    ✗ Myth · 迷思A computer stores the letter A as a tiny picture of an A.電腦把字母 A 存成一個小小的 A 的圖。

    ✓ Fact · 事實It stores a number, 65. The shape you see comes from a font, which is a separate file that tells the screen how to draw each numbered character.它存的是一個數：65。你看到的形狀來自「字型」，那是另一個檔案，告訴螢幕每個編號的字要怎麼畫。

    ✗ Myth · 迷思A row of bits knows whether it is a letter, a color, or a sound.一排位元自己知道它是字、是顏色，還是聲音。

    ✓ Fact · 事實It does not. 01000001 is 65, or A, or a shade of red, depending on the code used to read it. Open a file with the wrong code and you get nonsense.它不知道。01000001 是 65、是 A、還是某種紅，要看用哪一套編碼去讀。用錯編碼打開檔案，看到的就是亂碼。

    ✗ Myth · 迷思An emoji is a small picture that is sent to your friend.表情符號是一張小圖，傳給了朋友。

    ✓ Fact · 事實An emoji is a character with a number in Unicode, like a letter. Only the number is sent. Each phone or computer maker draws its own picture for that number, so the same emoji can look different on a friend’s screen.表情符號和字母一樣，是 Unicode 裡有編號的字元。傳出去的只有編號；每家手機或電腦廠商各自替這個編號畫圖，所以同一個表情符號在朋友的螢幕上可能長得不一樣。

    ✗ Myth · 迷思The character “5” and the number 5 are the same thing to a computer.對電腦來說，字元「5」和數 5 是同一個東西。

    ✓ Fact · 事實The character “5” is stored as number 53. A program has to convert the character into the number 5 before it can do arithmetic with it.字元「5」存起來是 53 號。程式要先把這個字元轉成數 5，才能拿它來計算。

    Before You Start · 動手之前

    A few reminders 幾個提醒

    • The developer console is a powerful tool. Type only what this lesson shows, and never paste in code that a stranger or a website tells you to paste: it could give away your account.開發人員主控台是很強的工具。只輸入這一課寫的那幾行；陌生人或網站叫你貼進去的程式碼絕對不要貼，那可能會讓你的帳號被盜。
    • Changes you make with Inspect are only on your own screen. They disappear when you reload, and they do not change the real website.用「檢查」改的東西只在你自己的螢幕上，重新整理就不見了，不會改到真正的網站。
    • Use a school or family computer only with permission, and do not change its settings.用學校或家裡的電腦要先得到同意，也不要更改設定。
    • Look away from the screen every 20 minutes and let your eyes rest.每看 20 分鐘螢幕，就把視線移開，讓眼睛休息一下。

    Classroom Activity 1 · 課堂活動一

    Secret Messages in ASCII 用 ASCII 傳密碼信

    You need · 準備材料

    • A code table on the board: A = 65, B = 66, C = 67 … Z = 90黑板上的對照表：A＝65、B＝66、C＝67……Z＝90
    • Paper and a pencil for each pair每組一張紙、一枝鉛筆
    • Eight small cards or coins (optional), to use as switches八張小卡片或硬幣（可有可無），當成開關

    Steps · 步驟

    1. With a partner, choose a secret word of three or four capital letters. Do not show it to other pairs.兩人一組，選一個三到四個大寫字母的祕密單字，不要讓別組看到。
    2. Look up the number of each letter in the table. For example, CAT is 67, 65, 84.在表上查出每個字母的編號。例如 CAT 是 67、65、84。
    3. Write each number as eight bits, the way you learned in Lesson 1. 65 is 0100 0001.用第一課學的方法，把每個數寫成八個位元。65 是 0100 0001。
    4. Trade papers with another pair. Turn their bits back into numbers, and the numbers back into letters.和另一組交換。把對方的位元變回數，再把數變回字母。

    Then ask: what if one pair had used a different table, with A = 1? The same bits would spell a different word, or nothing at all. That is what happens when a file is opened with the wrong code. In Taiwan’s junior high Information Technology curriculum, this lesson fits “Data representation, processing, and analysis” (資 D-IV-1 and 資 D-IV-2; the notes list sampling and the idea of encoding).
    接著問：如果有一組用的是另一張表（A＝1），會怎樣？同樣的位元會拼出另一個字，或者什麼都不是。這就是用錯編碼打開檔案時發生的事。對照十二年國教國中「資訊科技」的學習內容，這一課屬於「資料表示、處理及分析」（資 D-IV-1、資 D-IV-2；附錄的說明列有「取樣、量化」與「編碼的概念」）。

    Classroom Activity 2 · 課堂活動二

    Check It on Your Own Computer 在自己的電腦上驗證

    You need · 準備材料

    • A computer with a web browser such as Chrome, Edge, Firefox, or Safari一台有瀏覽器的電腦（Chrome、Edge、Firefox 或 Safari）
    • This page這一頁

    Steps · 步驟

    1. Open the browser’s developer tools and choose the Console tab. In Chrome, press Command+Option+J on a Mac, or Control+Shift+J on Windows.打開瀏覽器的開發人員工具，選「Console」（主控台）分頁。Chrome：Mac 按 Command＋Option＋J，Windows 按 Control＋Shift＋J。
    2. Type 'A'.charCodeAt(0) and press Enter. The browser answers 65.輸入 'A'.charCodeAt(0) 再按 Enter，瀏覽器會回答 65。
    3. Type '永'.codePointAt(0) and press Enter. It answers 27704. Now go the other way: String.fromCodePoint(27704).輸入 '永'.codePointAt(0) 再按 Enter，它會回答 27704。再反過來試：String.fromCodePoint(27704)。
    4. Now find a color. Right-click any colored part of this page and choose Inspect. In the Styles panel, look for a color written as rgb(…) or as # followed by six characters.接著找一個顏色。在這一頁任何有顏色的地方按右鍵，選「檢查」。在 Styles（樣式）面板裡找寫成 rgb(…)，或是 # 後面接六個字元的顏色。

    A color written as #d62828 is the same three numbers in another form: d6 is 214, 28 is 40, and 28 is 40. That is the red of the apple in the model. Web developers read these numbers every day. In Safari you must first turn on the developer tools in Settings, and menu names differ a little between browsers.
    寫成 #d62828 的顏色，是同樣三個數的另一種寫法：d6 是 214，28 是 40，28 是 40——就是模型裡蘋果的紅。寫網站的人每天都在讀這些數。Safari 要先在設定裡打開開發人員工具；各家瀏覽器的選單名稱略有不同。
