Why Does a Computer Need Two Kinds of Memory?電腦為什麼要有兩種記憶？

Big idea · 一句話看懂

No single kind of memory is fast, large, cheap, and lasting all at once. So a computer uses two that work together. Memory is fast but small, and it forgets when the power goes off. Storage is slower but large, and it keeps things without power.
沒有哪一種記憶能同時又快、又大、又便宜、又留得住。所以電腦用兩種，搭配著用。記憶體很快，可是小，而且一斷電就忘光；儲存裝置比較慢，可是大，而且沒有電也留得住。

Unit 7: Why Does a Computer Need Two Kinds of Memory?

In Lesson 5 you met two parts that both keep things: memory and storage. That seems wasteful. Why not build one kind of memory that is fast, holds everything, and never forgets? Engineers would love to. The trouble is that no single kind of memory can do all of that. The fast kinds are small and expensive. The large, cheap kinds are slow. So a computer uses two, and lets each do what it is good at.

在第五課，你認識了兩個都是用來「放東西」的零件：記憶體和儲存裝置。這看起來很浪費。為什麼不做一種又快、什麼都放得下、又永遠不會忘的記憶就好？工程師也很想。問題是，沒有哪一種記憶做得到全部：快的那幾種又小又貴，又大又便宜的那幾種很慢。所以電腦用兩種，讓它們各做自己擅長的事。

Think of a desk and a bookcase. The bookcase holds hundreds of books, but to use one you have to get up and fetch it. The desk holds only a few things, but they are right in front of you. Storage is the bookcase. Memory is the desk. In Lesson 6 you saw that the processor fetches from memory again and again without stopping, so memory has to be the fast one.

想像一張書桌和一座書櫃。書櫃放得下幾百本書，可是要用哪一本，都得站起來去拿。書桌只放得下幾樣東西，可是它們就在你面前。儲存裝置是書櫃，記憶體是書桌。第六課說過，處理器一刻不停地從記憶體拿東西，所以記憶體一定得是快的那一個。

When you open a program, the computer copies it from storage into memory. The first time is the slow part, like walking to the bookcase. After that, the processor works with the copy in memory, which is quick. The original stays in storage. When you change a file, you are changing only the copy in memory. Saving means copying the new version back to storage.

你打開一個程式的時候，電腦會把它從儲存裝置抄一份到記憶體。第一次是慢的那一段，就像走到書櫃去拿。之後處理器用的是記憶體裡那一份，很快。原來那一份還留在儲存裝置。你修改一個檔案的時候，改的只是記憶體裡的那一份；「存檔」就是把新的版本抄回儲存裝置。

Memory has one more weakness: it needs power to hold on to anything. Switch the computer off, and everything in memory is gone. Storage does not lose its contents when the power is turned off. That is why work you have not saved can disappear, and why a computer needs a little time to start up: it has to copy what it needs from storage into memory all over again.

記憶體還有一個弱點：它要有電才留得住東西。電腦一關，記憶體裡的東西就全部不見了。儲存裝置在斷電之後不會失去內容。這就是為什麼沒存檔的東西會消失，也是為什麼電腦開機要花一點時間：它得把需要的東西重新從儲存裝置抄進記憶體。

What if you open more than memory can hold? The computer does not simply give up. It takes something you are not using at the moment and moves it out of memory onto storage, to make room. When you go back to it, the computer has to move it in again. Everything still works, but storage is slower, so the computer feels slow. That is the usual reason a computer with too many things open drags.

如果你打開的東西比記憶體放得下的還多呢？電腦不會就這樣放棄。它會把你這時候沒在用的某樣東西，從記憶體移到儲存裝置，把位置空出來。等你回頭要用它，電腦又得把它搬回來。東西都還能用，可是儲存裝置比較慢，所以電腦用起來就慢。開太多東西的電腦會拖拖拉拉，通常就是這個原因。

So the two kinds of memory are a team. Storage is large and lasting. Memory is fast and close to the processor. A typical computer has many times more storage than memory, because storage is the cheaper of the two. In fact a computer has more than two levels: from tiny, very fast memory inside the processor itself, to memory, to storage, each one larger and slower than the one before it.

所以這兩種記憶是一個團隊。儲存裝置又大又留得住；記憶體又快，又離處理器近。一般的電腦，儲存空間是記憶體的好多倍，因為儲存裝置是比較便宜的那一種。其實電腦不只兩層：從處理器裡面非常小、非常快的記憶，到記憶體，再到儲存裝置，每一層都比前一層更大、也更慢。
Read aloud · 課文朗讀

Questions · 閱讀理解

Why does a computer not use just one kind of memory?

Because no single kind is fast, large, cheap, and lasting all at once. The fast kinds are small and expensive, and the large, cheap kinds are slow. Using two lets each do what it is good at.

What happens to a file when you open it, change it, and save it?

Opening it copies it from storage into memory. Changing it changes only the copy in memory. Saving it copies the new version back to storage, where it stays even when the power is off.

Why does a computer get slow when too many things are open?

Memory fills up, so the computer moves things you are not using out to storage and has to move them back in when you return to them. Storage is slower than memory, so everything takes longer.

Stories Behind the Two Memories · 兩種記憶的故事

A staircase of memories, a trick called virtual memory, a colored graph, and a habit 一道記憶的階梯、一招叫虛擬記憶體、一張有顏色的圖、一個習慣

Four short stories about memory and storage.
關於記憶體和儲存裝置的四個小故事。

Hierarchy · 階層

Not two levels, but a staircase不只兩層，而是一道階梯

This lesson talks about two kinds of memory, but Britannica describes a whole hierarchy. At the top are very small, fast, and expensive registers inside the processor. Next comes small, fast cache memory, then the larger main memory, then very large hard disks, and finally slow, inexpensive backup storage. Each step down is bigger and slower than the one above. The counter and the box called A in Lesson 6 were registers.
這一課講的是兩種記憶，但大英百科描述的是一整個階層。最上面是處理器裡非常小、非常快、也很貴的暫存器；接著是小而快的快取記憶體，再來是比較大的主記憶體，然後是非常大的硬碟，最後是又慢又便宜的備份儲存。每往下一階，都比上面那一階更大、更慢。第六課的計數器和那個叫 A 的格子，就是暫存器。

Virtual memory · 虛擬記憶體

Pretending there is more room假裝位置比較多

What you saw when the desk filled up has a name: virtual memory. Britannica explains that it gives each program a portion of main memory and stores the rest of its code and data on a hard disk, automatically copying blocks to and from main memory as needed. The program does not have to know. It works as if it had all the memory it wanted, and the computer does the fetching and carrying.
桌子滿了的時候你看到的那件事，有個名字：虛擬記憶體。大英百科的解釋是：它給每個程式一部分的主記憶體，把程式其餘的程式碼和資料放在硬碟上，需要的時候再自動把一塊一塊的內容在兩邊抄來抄去。程式本身不需要知道這些，它照樣工作，好像想要多少記憶體都有，搬來搬去的事由電腦負責。

Green, yellow, red

A graph that shows the squeeze一張看得出擠不擠的圖

A Mac shows this in its Activity Monitor app. The Memory pane displays how much memory the Mac is using and how often it is swapping memory between RAM and the startup disk. A graph called Memory Pressure is green when the computer is using its RAM efficiently, yellow when it might eventually need more, and red when it needs more RAM.
Mac 在「活動監視器」這個 App 裡把這件事顯示出來。「記憶體」那一頁會顯示 Mac 用了多少記憶體，以及它多常在 RAM 和開機磁碟之間交換記憶體。有一張叫「記憶體壓力」的圖：電腦有效率地使用 RAM 時是綠色，之後可能需要更多時是黃色，需要更多 RAM 時是紅色。

Save · 存檔

Why “save” exists at all為什麼會有「存檔」這回事

Saving is not a ceremony. It is the moment your work is copied from the fast memory that forgets to the slower storage that remembers. Everything in this lesson explains that one button: you work in memory because it is fast, and you save to storage because it lasts. However an app handles saving, the rule underneath is the same: what is only in memory is gone when the power goes off.
存檔不是一個儀式。它是把你的工作，從「很快但會忘」的記憶體，抄到「比較慢但記得住」的儲存裝置的那一刻。這一課講的所有事情，都在解釋這一個按鈕：在記憶體裡工作，因為它快；存到儲存裝置，因為它留得住。不管 App 怎麼處理存檔，底下的規則都一樣：只在記憶體裡的東西，斷電就沒了。

Myth vs. Fact · 常見迷思

Four things people get wrong 四個常見的誤會

✗ Myth · 迷思Opening a file moves it out of storage.打開檔案，就是把它從儲存裝置搬走。

✓ Fact · 事實Opening copies it. The original stays in storage, which is why closing a file without saving leaves the old version untouched.打開是「抄一份」。原來那一份還在儲存裝置裡，所以不存檔就關掉，舊的版本還是原封不動。

✗ Myth · 迷思More storage makes a computer faster.儲存空間越大，電腦就越快。

✓ Fact · 事實More storage lets you keep more. It is more memory that lets you keep more things open at once without the slow trips to storage.儲存空間大，是能「放」更多東西。能同時開更多東西而不用一直慢慢跑去儲存裝置的，是比較多的記憶體。

✗ Myth · 迷思When memory is full, the computer starts losing things.記憶體滿了，電腦就開始丟東西。

✓ Fact · 事實It does not lose them. It moves what is not being used to storage and brings it back when needed. The cost is speed, not your work.它不會把東西丟掉，而是把暫時沒在用的移到儲存裝置，需要時再搬回來。代價是速度，不是你的東西。

✗ Myth · 迷思Free memory is good, so a computer should keep its memory as empty as possible.記憶體空著比較好，所以應該盡量讓它空著。

✓ Fact · 事實Apple’s guide says that free or unused memory does not necessarily improve performance. A computer does best by making good use of all the memory it has.Apple 的說明寫道，有空著沒用的記憶體，效能不見得比較好。電腦把手上所有的記憶體都好好用上，表現才最好。

Before You Start · 動手之前

A few reminders 幾個提醒

  • Do not switch a real computer off at the wall or hold the power button to see what is lost. Shut it down the normal way.不要為了看看什麼會不見，就直接拔真電腦的插頭或長按電源鍵。請用正常的方式關機。
  • Save your work before you try anything in the second activity, and save often in general.做第二個活動之前，先把手上的東西存檔；平常也要常常存檔。
  • In Activity Monitor or Task Manager, only look. Do not quit or end anything in the list.在「活動監視器」或「工作管理員」裡只要看就好，不要結束清單裡的任何東西。
  • Use a school or family computer only with permission, and do not change its settings.用學校或家裡的電腦要先得到同意，也不要更改設定。

Classroom Activity 1 · 課堂活動一

The Desk Game 書桌遊戲

You need · 準備材料

  • A table at the front of the room: the desk, with four spaces marked in tape教室前面的一張桌子當書桌，用膠帶標出四個位置
  • A shelf or box at the back of the room: the bookcase教室後面的一個架子或箱子當書櫃
  • Eight folders, each holding one sheet of paper, with two photocopies of each sheet八個資料夾，每個裡面放一張紙，每張紙另外影印兩份
  • A pencil and a stopwatch一枝鉛筆和一個碼錶

Steps · 步驟

  1. The folders stay in the bookcase at all times. One student is the processor and sits at the desk. Another is the runner. A third keeps time.資料夾永遠留在書櫃裡。一位同學當處理器，坐在書桌前；一位當跑腿的；一位負責計時。
  2. The teacher calls out a folder. If a copy is on the desk, the processor touches it and says “Got it!” If not, the runner walks to the bookcase and brings back a photocopy. Time both.老師喊一個資料夾的名字。桌上有它的影本，處理器就摸一下說「拿到了！」；沒有的話，跑腿的走到書櫃拿一份影本回來。兩種情況都計時。
  3. When the desk already has four copies and a fifth is called, the runner must first carry one copy back to the bookcase. Which one should go?桌上已經有四份影本、老師又喊第五樣的時候，跑腿的得先把一份影本送回書櫃。該送哪一份回去？
  4. Write on one of the copies with the pencil. Then the teacher says “Power off!” and sweeps everything off the desk. Look in the bookcase: is your writing there?用鉛筆在其中一份影本上寫字。接著老師說「停電！」，把桌上的東西全部掃掉。去書櫃看看：你寫的字在那裡嗎？

Compare the times: touching a copy on the desk against a walk across the room. Then play again, and this time carry the written copy back to the bookcase before the power goes off. That walk is saving. In Taiwan’s junior high Information Technology curriculum, this lesson matches the topic “System platforms”: 資 S-IV-2, whose notes list memory.
比一比時間：摸一下桌上的影本，和走過整間教室。接著再玩一次，這次在停電之前，把寫了字的那一份送回書櫃。那一趟路就是存檔。對照十二年國教國中「資訊科技」的學習內容，這一課對應「系統平台」主題：資 S-IV-2 系統平台之組成架構與基本運作原理（附錄的說明列有記憶體）。

Classroom Activity 2 · 課堂活動二

Check It on Your Own Computer 在自己的電腦上驗證

You need · 準備材料

  • A Windows or Mac computer一台 Windows 或 Mac 電腦
  • The numbers you wrote down in Lesson 5, or the steps from that lesson第五課寫下來的那幾個數字，或照那一課的步驟再查一次
  • Paper and a pencil紙和鉛筆

Steps · 步驟

  1. Find how much memory your computer has and how much storage it has, both in gigabytes. Lesson 5 shows where to look.找出你的電腦有多少記憶體、多少儲存空間，單位都是 GB。在哪裡看，第五課有教。
  2. Divide the storage by the memory. How many times bigger is the bookcase than the desk?把儲存空間除以記憶體。書櫃是書桌的幾倍大？
  3. On a Mac, open Activity Monitor and click Memory. On Windows, open Task Manager, select the Performance tab, and look for Memory. How much memory is in use right now?Mac：打開「活動監視器」，按「記憶體」（Memory）。Windows：打開「工作管理員」，選 Performance（效能）分頁，找到 Memory（記憶體）。現在用了多少記憶體？
  4. Open a few more apps, look again, then close them and look once more. On a Mac, watch the color of the Memory Pressure graph.多開幾個 App，再看一次；把它們關掉，再看一次。Mac 上可以注意「記憶體壓力」那張圖的顏色。

A computer with 16 GB of memory and 512 GB of storage has 32 times as much storage as memory. A computer with 8 GB and 1 TB has 125 times as much. Whatever your numbers are, the bookcase is far bigger than the desk. The names of menus differ a little between versions of Windows and macOS.
記憶體 16 GB、儲存空間 512 GB 的電腦，儲存空間是記憶體的 32 倍；8 GB 配 1 TB 的電腦是 125 倍。不管你的數字是多少，書櫃都比書桌大得多。不同版本的 Windows 和 macOS，選單的名稱會略有不同。
