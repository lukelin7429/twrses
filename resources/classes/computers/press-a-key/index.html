How Computers Work · Unit 2 · Lesson 8 · 電腦概論 單元二 第八課

What Happens When You Press a Key?按下一個鍵，發生了什麼？

Follow one key in 3D, from the keyboard, along the cable, through the processor and memory, to the screen. At every stop it is something different: a switch, a key number, a character number, eight bits, and at last a pattern of pixels. Then guess what it is at each stop, sort input from output, and test the keys on your own keyboard.
在 3D 裡跟著一個鍵走一趟：從鍵盤出發，沿著線，經過處理器和記憶體，走到螢幕。每一站它都是不一樣的東西：一個開關、一個鍵的編號、一個字元的編號、八個位元，最後是一片像素。接著猜猜它在每一站是什麼、分辨輸入和輸出，再測測自己鍵盤上的鍵。

Big idea · 一句話看懂

A computer takes something in, works on it, and sends something out: input, processing, output. A keyboard does not send a letter. It sends a number that says which key was pressed. The computer turns that into a character number, keeps it in memory as bits, and lights pixels on the screen. It is 0s and 1s the whole way.
電腦把東西收進來、處理它、再送出去：輸入、處理、輸出。鍵盤送出的不是一個字母，而是一個「哪一個鍵被按了」的編號。電腦把它變成字元的編號，用位元放在記憶體裡，再讓螢幕上的像素亮起來。從頭到尾都是 0 和 1。

Unit 8: What Happens When You Press a Key?

Press the key marked A, and the letter a appears on the screen. It seems to happen at once, and it seems simple. It is not simple. Between your finger and the screen, that key press changes form four times. Let us follow it.

按下標著 A 的那個鍵，螢幕上就出現字母 a。這件事好像是一瞬間發生的，也好像很簡單。其實不簡單。從你的手指到螢幕之間，這一次按鍵換了四次樣子。我們跟著它走一趟。

Under each key there is a switch. When you press the key, the switch closes, and the keyboard sends the computer a number. The number does not mean a letter. It means a key: it says which key was pressed. On a USB keyboard, the A key is key number 4. The keyboard sends the same number whether you are holding Shift or not, and it reports again when you let the key go.

每個鍵的下面都有一個開關。你按下鍵，開關接通，鍵盤就送一個數給電腦。這個數指的不是一個字母，而是一個鍵：它說的是「哪一個鍵被按了」。在 USB 鍵盤上，A 鍵是第 4 號鍵。不管你有沒有按住 Shift，鍵盤送出的都是同一個數；你放開鍵的時候，它還會再回報一次。

Now the computer has to decide what the key means. It looks at three things: the key number, whether Shift is down, and the keyboard layout you have chosen. From these it picks a character. Key 4 with no Shift gives a. Key 4 with Shift gives A. As you saw in Lesson 2, every character has its own number: a is 97, and A is 65.

接下來，電腦要決定這個鍵是什麼意思。它看三樣東西：鍵的編號、Shift 有沒有按著、你選的鍵盤配置。從這三樣，它挑出一個字元。第 4 號鍵、沒按 Shift，是 a；第 4 號鍵、按著 Shift，是 A。第二課說過，每個字元都有自己的編號：a 是 97，A 是 65。

The number 97 is stored in memory as eight bits: 01100001. The program you are typing in now has a new character to work with, and the processor carries out that program’s instructions, one small step at a time, just as in Lesson 6. If you save your work, the bits are copied to storage, as in Lesson 7.

97 這個數，以八個位元放進記憶體：01100001。現在，你正在打字的那個程式多了一個字元可以用；處理器一小步一小步地執行那個程式的指令，就像第六課那樣。如果你存檔，這些位元會被抄到儲存裝置，就像第七課那樣。

You still cannot see anything. To show the character, the computer needs a shape for it, and the shapes come from a font. A font is a collection of shapes for characters. The computer uses the font to decide which pixels on the screen to light, and the letter appears. Choose a different font and other pixels light up, but the character in memory is still 97.

到這裡，你還是什麼都看不到。要把這個字元顯示出來，電腦需要它的形狀，而形狀來自字型。字型就是一整套字元的形狀。電腦用字型決定螢幕上哪些像素要亮，字母就出現了。換一種字型，亮的像素就不一樣，可是記憶體裡的字元還是 97。

This is the pattern of every computer: input, processing, output. An input device, such as a keyboard, a mouse, or a microphone, turns something from the outside world into electrical signals in binary code. The computer works on them. An output device, such as a screen, a printer, or a speaker, turns the signals back into something a person can understand. Switches, bits, codes, a processor, memory: everything in the first eight lessons took part in that one key press.

每一台電腦都照這個模式工作：輸入、處理、輸出。輸入裝置（像鍵盤、滑鼠、麥克風）把外面世界的東西變成二進位的電訊號；電腦處理這些訊號；輸出裝置（像螢幕、印表機、喇叭）再把訊號變回人看得懂、聽得懂的東西。開關、位元、編碼、處理器、記憶體——前八課講過的每一樣東西，都參與了這一次按鍵。

Questions · 閱讀理解

What does a keyboard send to the computer when you press a key?

It sends a number that says which key was pressed. It does not send a letter. The computer decides which character the key means.

Why do a and A come from the same key but have different numbers in memory?

The key sends the same key number both times. The computer looks at the key number, the Shift key, and the keyboard layout, and picks a different character: a is 97, and A is 65.

Name one input device and one output device, and say what each one does.

For example, a keyboard is an input device: it turns key presses into signals the computer can use. A screen is an output device: it turns the computer’s signals into pictures a person can see.

Stories Behind the Keys · 按鍵的故事

A key that reports twice, one keyboard for many languages, a typewriter without Shift, and letters without shapes 回報兩次的鍵、一個鍵盤打很多種語言、沒有 Shift 的打字機、沒有形狀的字母

Four short stories about what a key press really is.
關於「一次按鍵到底是什麼」的四個小故事。

Down and up · 按下與放開

A key reports twice一個鍵回報兩次

Microsoft’s guide for programmers explains that each key on a keyboard has a unique value called a scan code, and that a keyboard generates two scan codes when you type a key: one when you press it and another when you release it. That is how a game knows you are still holding a key down, and how the computer knows that Shift is still held while you press something else.
微軟寫給程式設計師的說明提到：鍵盤上每個鍵都有一個獨一無二的值，叫做掃描碼（scan code）；你打一個鍵，鍵盤會產生兩個掃描碼，按下去一個，放開又一個。遊戲就是這樣知道你還按著某個鍵沒放，電腦也是這樣知道你按別的鍵時 Shift 還按著。

Y and Z · Y 和 Z

One keyboard, many languages一個鍵盤，很多種語言

The USB keyboard standard gives an example. On a North American keyboard there is a Y key; in Germany the key in that position is typically Z. The standard says the maker should not change the electronics. Both keyboards send the same key number, and only the letter printed on the key is different. The computer’s layout setting decides which letter it means.
USB 鍵盤標準裡舉了一個例子。北美的鍵盤上有一個 Y 鍵，在德國，同一個位置的鍵通常是 Z。標準說，製造商不必更動裡面的電子零件：兩種鍵盤送出同一個鍵的編號，不一樣的只有印在鍵帽上的字母。到底是哪個字母，由電腦的鍵盤配置設定決定。

1878

The first typewriter had no Shift第一台打字機沒有 Shift

According to Britannica, the first practical typewriter was built by the American inventor Christopher Latham Sholes, patented in 1868, and sold from 1874 by the Remington company. It wrote capital letters only. The first shift-key typewriter, the Remington Model 2, appeared in 1878: each bar carried two letters, a capital and a small one, and the shift key chose between them. Britannica adds that the positions of the characters on that early keyboard conform almost exactly to the arrangement that is now universal.
根據大英百科，第一台實用的打字機由美國發明家蕭爾斯（Christopher Latham Sholes）製造，1868 年取得專利，1874 年起由雷明頓公司販售。它只能打大寫字母。第一台有 Shift 鍵的打字機是 1878 年的雷明頓二號：每根字桿上有兩個字，一大寫一小寫，由 Shift 鍵決定用哪一個。大英百科還說，那台早期機器上各個字元的位置，和現在通用的排法幾乎完全一樣。

Character and glyph · 字元與字形

A character has no shape of its own字元自己沒有形狀

The Unicode Standard’s glossary keeps two ideas apart. A character is what is stored: a number. A glyph is a shape used to show it. A font is “a collection of glyphs used for the visual depiction of character data,” and rendering is the process of choosing glyphs and making them visible on a display. So the 97 in memory is not round or tall or bold. It gets a shape only at the last stop.
Unicode 標準的詞彙表把兩個概念分得很清楚。字元（character）是存起來的東西：一個數。字形（glyph）是用來顯示它的形狀。字型（font）是「一整套用來把字元資料顯示出來的字形」，而算繪（rendering）就是挑選字形、讓它們在顯示器上看得見的過程。所以記憶體裡的 97 沒有圓不圓、高不高、粗不粗的問題。它到最後一站才有形狀。

Myth vs. Fact · 常見迷思

Four things people get wrong 四個常見的誤會

✗ Myth · 迷思The keyboard sends the letter A to the computer.鍵盤把字母 A 送給電腦。

✓ Fact · 事實It sends a number that says which key was pressed. The computer decides which character that key means.它送的是一個編號，說的是哪一個鍵被按了。這個鍵代表哪個字元，是電腦決定的。

✗ Myth · 迷思Holding Shift makes the A key send something different.按住 Shift，A 鍵送出的東西就不一樣。

✓ Fact · 事實The USB keyboard standard says a key does not send extra codes because of Shift. The A key sends the same number either way; Shift is reported separately.USB 鍵盤標準寫明，鍵不會因為 Shift 而多送別的碼。A 鍵送的編號都一樣，Shift 是另外回報的。

✗ Myth · 迷思The letter printed on a key decides what it types.鍵上印的字母，決定它打出什麼。

✓ Fact · 事實The printing is only a label for you. The computer’s keyboard layout setting decides, which is why one keyboard can type in many languages.印在上面的字只是給你看的標籤。決定的是電腦的鍵盤配置設定，所以同一個鍵盤可以打很多種語言。

✗ Myth · 迷思A space is nothing.空白就是什麼都沒有。

✓ Fact · 事實A space is a character with its own number, 32, and it takes up room in memory like any letter. It just lights no pixels.空白是一個字元，有自己的編號 32，和任何字母一樣要占記憶體。它只是不點亮任何像素。

Before You Start · 動手之前

A few reminders 幾個提醒

  • Do not pull the keys off a keyboard to look at the switches. On many keyboards they break or do not go back on.不要為了看開關而把鍵帽拔下來。很多鍵盤的鍵一拔就壞，或裝不回去。
  • Never type a password into a page or program that is only showing you which keys you press.只是用來顯示你按了什麼鍵的網頁或程式，絕對不要在裡面打密碼。
  • Do not change the keyboard layout on a school or family computer without asking. If you change it, change it back.沒有問過，不要改學校或家裡電腦的鍵盤配置。改了就要改回來。
  • Use a school or family computer only with permission.用學校或家裡的電腦要先得到同意。

Classroom Activity 1 · 課堂活動一

The Key Press Relay 按鍵接力

You need · 準備材料

  • Five desks in a row, labeled Keyboard, Cable, Processor, Memory, and Screen排成一排的五張桌子，分別標上：鍵盤、線、處理器、記憶體、螢幕
  • Small cards and pencils小卡片和鉛筆
  • A lookup sheet for the Processor desk: key 4 → a (97), key 4 with Shift → A (65), key 30 → 1 (49), key 30 with Shift → ! (33), key 44 → space (32)給「處理器」那一桌的對照表：第 4 號鍵 → a（97）、第 4 號鍵加 Shift → A（65）、第 30 號鍵 → 1（49）、第 30 號鍵加 Shift → !（33）、第 44 號鍵 → 空白（32）
  • Squared paper for the Screen desk, with a grid 5 squares across and 7 down給「螢幕」那一桌的方格紙，畫好橫 5 格、直 7 格的格子

Steps · 步驟

  1. The teacher whispers a key to the Keyboard student, for example “the A key, with Shift.” The Keyboard writes only a key number on a card, 4, and adds “Shift” if it is held. No letters allowed.老師小聲告訴「鍵盤」同學一個鍵，例如「A 鍵，加 Shift」。「鍵盤」只能在卡片上寫鍵的編號 4，有按 Shift 就加寫「Shift」。不可以寫字母。
  2. The Cable carries the card to the Processor, who uses the lookup sheet and writes the character number on a new card: 65.「線」把卡片送給「處理器」。「處理器」查對照表，在新的卡片上寫下字元的編號：65。
  3. Memory writes that number as eight bits, 01000001, and passes it on.「記憶體」把那個數寫成八個位元 01000001，再傳下去。
  4. The Screen turns the bits back into a number, finds the character, and colors in squares on the grid to draw it. The class reads the screen: is it the key the teacher whispered?「螢幕」把位元換回數字、找出是哪個字元，在方格上塗出它的樣子。全班看螢幕：是老師小聲說的那個鍵嗎？

Ask afterward: which student was the first to know it was a letter? Then let two Screen students draw the same character. Their drawings will differ a little, and that is what a font is. In Taiwan’s junior high Information Technology curriculum, this lesson matches the topic “System platforms”: 資 S-IV-2, whose notes list input and output.
做完問大家：哪一位同學是第一個知道它是字母的人？再請兩位「螢幕」同學畫同一個字元，兩個人畫的會有一點不一樣，這就是字型。對照十二年國教國中「資訊科技」的學習內容，這一課對應「系統平台」主題：資 S-IV-2 系統平台之組成架構與基本運作原理（附錄的說明列有輸入輸出）。

Classroom Activity 2 · 課堂活動二

Check It on Your Own Computer 在自己的電腦上驗證

You need · 準備材料

  • A computer with a keyboard that has real keys一台有實體鍵盤的電腦
  • The “Ask Your Own Keyboard” box on this page這一頁的「問問自己的鍵盤」那個框框
  • Paper and a pencil紙和鉛筆

Steps · 步驟

  1. Click the box and press the A key. Write down the two answers: which key, and what it typed.點一下框框，按 A 鍵。把兩個答案寫下來：哪一個鍵、打出什麼。
  2. Hold Shift and press A again. Which answer changed, and which stayed the same?按住 Shift 再按一次 A。哪一個答案變了？哪一個沒變？
  3. Do the same with the 1 key and with the space bar. Write the character number for each.用 1 鍵和空白鍵各做一次，把每個字元的編號寫下來。
  4. If your keyboard has a number pad, press the 1 there, and then the 1 above the letters. Both type 1. Do they have the same key name?如果你的鍵盤有數字鍵區，按那裡的 1，再按字母上方的 1。兩個都打出 1，它們的鍵名一樣嗎？

With the U.S. layout you should find: A key, a = 97 and A = 65; 1 key, 1 = 49 and ! = 33; space bar, 32. The two numbers for a and A differ by exactly 32, which is one bit. If your numbers are different, your computer is probably set to another keyboard layout, and that is the lesson too.
用美式配置應該會看到：A 鍵，a＝97、A＝65；1 鍵，1＝49、!＝33；空白鍵 32。a 和 A 這兩個數剛好差 32，也就是只差一個位元。如果你看到的數字不一樣，你的電腦大概設了別的鍵盤配置——這也正是這一課要說的事。
