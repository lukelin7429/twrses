What Does an Operating System Do?作業系統在做什麼？

One chef, four orders, and a rule: work on one for a moment, then move to the next. Watch the chef take turns in 3D, change how long each turn lasts, and see what it costs to switch. Then tune the turns for three programs so the music never breaks up, and decide which jobs belong to the operating system.
一位廚師、四張點單，還有一條規則：每張做一下，就換下一張。在 3D 裡看廚師怎麼輪流，改一改每一輪做多久，看看換手要付出什麼代價。接著替三個程式調出剛好的長短，讓音樂不會斷斷續續，再分辨哪些工作是作業系統的。

Big idea · 一句話看懂

A processor can do only one thing at a time. The operating system is the program that lets many programs share it: each one gets a short turn, then waits while the others have theirs. The turns come around so quickly that everything seems to run at once. The operating system also shares out memory, files, and devices.
處理器一次只能做一件事。作業系統是讓很多程式共用處理器的那個程式：每個程式輪到一小段時間，然後等別的程式輪完。輪得夠快，看起來就像全部同時在跑。作業系統也負責分配記憶體、檔案和各種裝置。

Unit 11: What Does an Operating System Do?

Right now a computer near you may be playing music, showing a web page, and waiting for someone to type. Yet in Lesson 6 you saw that a processor carries out one instruction at a time. So how can it do three things at once? The answer is that it does not. It only looks that way.

這一刻，你附近的某台電腦可能正在放音樂、顯示一個網頁，同時等著有人打字。可是第六課說過，處理器一次只執行一條指令。那它怎麼能同時做三件事？答案是：它並沒有。只是看起來像。

There is one program in charge of all the others: the operating system. An encyclopedia describes it as a program that manages a computer’s resources, especially the way they are shared among other programs. The resources are the processor, the memory, the storage, and the devices. Windows, Android, and iOS are operating systems.

有一個程式負責管理其他所有的程式，它就是作業系統（operating system）。百科全書對它的描述是：管理電腦資源的程式，特別是負責把這些資源分配給其他程式。資源指的是處理器、記憶體、儲存空間和各種裝置。Windows、Android、iOS 都是作業系統。

Think of one chef with four orders. The chef cannot cook them all at once, so the chef works on one for a moment, puts it down, and moves to the next. The operating system does the same with the processor. Each program is allowed to use it for a limited time, perhaps a fraction of a second. Then it must give up control and wait for its next turn. The turns come around so quickly that every program seems to be running all the time.

想像一位廚師有四張點單。廚師沒辦法四張一起做，所以先做其中一張一下子，放下，再換下一張。作業系統對處理器做的是同樣的事。每個程式只能用處理器一段有限的時間，可能只有幾分之一秒，然後就得交出控制權，等下一次輪到它。因為輪得很快，每個程式看起來都像一直在跑。

Switching is not free. While the chef is putting one order down and picking up the next, nothing is being cooked. In the same way, switching between programs uses the processor too. If the turns are very long, a program at the back of the line waits a long time, and music would break up. If the turns are very short, too much time goes to switching. The operating system has to find a balance.

換手不是免費的。廚師放下一張點單、拿起下一張的那段時間，沒有任何菜在做。同樣地，在程式之間切換，也要用到處理器。如果每一輪很長，排在後面的程式要等很久，音樂就會斷斷續續。如果每一輪很短，又有太多時間花在換手上。作業系統得在兩者之間找到平衡。

Sharing the processor is only one of its jobs. The operating system also decides which program gets which part of memory, and it keeps programs from interfering with each other. When memory fills up, it is the operating system that moves things out to storage, as you saw in Lesson 7. It keeps track of where every file is. And it stands between programs and devices: in Lesson 8, it was the operating system that turned a key number into a character.

分配處理器只是它的工作之一。作業系統還決定哪個程式用哪一塊記憶體，並且不讓程式互相干擾。記憶體滿了的時候，把東西移到儲存裝置的就是作業系統，這在第七課看過。它記著每一個檔案放在哪裡。它也站在程式和裝置之間：第八課裡，把鍵的編號變成字元的，就是作業系統。

Most programs finish a task and stop. An operating system keeps running until the computer is turned off. The first computers had none: they ran one program at a time, and a human operator looked after everything else. Today many computers have several processor cores, so a few things really can happen at the same moment. But there are usually many more programs than cores, so taking turns is still how it works.

大部分的程式做完一件事就結束。作業系統卻一直執行，直到電腦關機為止。最早的電腦沒有作業系統：它們一次只跑一個程式，其他的事都由一位操作員照料。今天很多電腦有好幾個處理器核心，所以真的有幾件事可以在同一刻進行。但是程式的數目通常比核心多得多，所以它還是靠輪流。

Questions · 閱讀理解

How can a computer seem to do several things at once when the processor does one thing at a time?

The operating system gives each program a short turn with the processor and then switches to the next. The turns come around so quickly that every program seems to be running all the time.

What goes wrong if the turns are very long? What goes wrong if they are very short?

With very long turns, a program at the back of the line waits a long time, so something like music would break up. With very short turns, too much time goes to switching and too little to real work.

Name three things, besides sharing the processor, that an operating system looks after.

For example: it shares out memory and keeps programs from interfering with each other, it keeps track of where files are, and it stands between programs and devices such as the keyboard.

Stories Behind Operating Systems · 作業系統的故事

Computers without one, many people on one machine, a student’s project, and the one in a home appliance 沒有作業系統的電腦、很多人共用一台機器、一個學生的計畫、家電裡的那一個

Four short stories about the program behind the programs.
關於「程式背後的那個程式」的四個小故事。

Mid-1950s · 1950 年代中期

At first there was none一開始並沒有

According to Britannica, the first digital computers had no operating systems. They ran one program at a time, that program had command of everything, and a human operator provided whatever else was needed. The first operating systems were developed in the mid-1950s. They were small “supervisor programs” that handled basic input and output, such as controlling punch card readers and printers, and kept accounts of how much processor time each job used, for billing.
根據大英百科，最早的數位電腦沒有作業系統。它們一次只跑一個程式，那個程式掌管一切，其他需要的事由一位操作員來做。最早的作業系統出現在 1950 年代中期，是一些小小的「監督程式」，處理基本的輸入和輸出（例如控制打孔卡片閱讀機和印表機），還替每個工作記下用了多少處理器時間，好用來算帳。

1960s · 1960 年代

Many people, one computer很多人，一台電腦

In the 1960s computers were very expensive, and many people wanted to use the same one. The answer was time-sharing: a system that let many users share one computer by switching rapidly between them. Britannica names two early time-sharing systems: CTSS, developed at the Massachusetts Institute of Technology, and the Dartmouth College Basic System. Each user had a turn so often that the computer seemed to belong to that person alone.
1960 年代的電腦非常貴，很多人都想用同一台。解決的辦法叫分時（time-sharing）：系統在很多使用者之間快速切換，讓大家共用一台電腦。大英百科舉出兩個早期的分時系統：麻省理工學院開發的 CTSS，以及達特茅斯學院的 BASIC 系統。每個使用者都很頻繁地輪到，所以感覺那台電腦好像是自己一個人的。

UNIX, Linux

From a lab to your pocket從實驗室到口袋

Britannica calls UNIX the most important operating system of the 1970s. It was developed by AT&T and became widely used in the 1980s, in part because it was free to universities. Later came Linux, an open-source version of UNIX developed in part by a group led by the Finnish computer science student Linus Torvalds and in part by a group led by the American programmer Richard Stallman. For phones and tablets, Britannica names two prominent operating systems: Apple’s iOS and Google’s Android.
大英百科說，UNIX 是 1970 年代最重要的作業系統。它由 AT&T 開發，1980 年代被廣泛使用，原因之一是大學可以免費使用。後來出現了 Linux，它是 UNIX 的開放原始碼版本，一部分由芬蘭的資訊科系學生托瓦茲（Linus Torvalds）帶領的團隊開發，一部分由美國程式設計師史托曼（Richard Stallman）帶領的團隊開發。至於手機和平板，大英百科舉出兩個主要的作業系統：Apple 的 iOS 和 Google 的 Android。

Real time · 即時

Not only in computers不只在電腦裡

Operating systems are not only for the machines on your desk. Britannica notes that special-purpose operating systems run on small computers that control assembly lines, aircraft, and even home appliances. They are called real-time systems, and they are designed to respond rapidly to sensors and to use what the sensors report to control machinery. A machine like that cannot keep its sensors waiting for a long turn.
作業系統不只用在書桌上的電腦。大英百科提到，有些特殊用途的作業系統，跑在控制生產線、飛機、甚至家用電器的小電腦上。它們叫做即時系統（real-time system），設計的目標是對感測器迅速做出反應，再根據感測器回報的資料控制機器。這樣的機器，可不能讓感測器等上很長的一輪。

Myth vs. Fact · 常見迷思

Four things people get wrong 四個常見的誤會

✗ Myth · 迷思A computer does many things at exactly the same moment.電腦在同一個瞬間做很多件事。

✓ Fact · 事實One processor core does one thing at a time. The operating system switches between programs so quickly that it looks like all at once. Extra cores help, but there are usually more programs than cores.一個處理器核心一次只做一件事。作業系統在程式之間切換得很快，所以看起來像同時。多幾個核心有幫助，但程式通常比核心多。

✗ Myth · 迷思The operating system is the desktop: the picture, the icons, and the windows.作業系統就是桌面：那張圖、那些圖示和視窗。

✓ Fact · 事實That is the part you can see. Most of the work is out of sight: sharing the processor, the memory, the files, and the devices among programs.那只是你看得到的部分。大部分的工作在看不到的地方：把處理器、記憶體、檔案和裝置分配給各個程式。

✗ Myth · 迷思Switching between programs costs nothing.在程式之間切換不花任何代價。

✓ Fact · 事實Britannica notes that switching between processes must itself use the processor. In the model, turns of 1 beat spend almost half the time on switching.大英百科指出，在行程之間切換，本身就要用到處理器。在模型裡，每一輪只做 1 拍的話，將近一半的時間都花在換手。

✗ Myth · 迷思Only computers and phones have operating systems.只有電腦和手機有作業系統。

✓ Fact · 事實Special-purpose operating systems run on the small computers that control assembly lines, aircraft, and even home appliances.控制生產線、飛機、甚至家用電器的小電腦，上面也跑著特殊用途的作業系統。

Before You Start · 動手之前

A few reminders 幾個提醒

  • In Activity Monitor or Task Manager, only look. Do not quit or end anything in the list: some of those items are parts of the operating system itself.在「活動監視器」或「工作管理員」裡只要看就好。不要結束清單裡的任何東西：其中有些就是作業系統自己的一部分。
  • Never switch a computer off at the wall to “stop a program.” Shut it down the normal way.不要為了「讓程式停下來」而直接拔插頭。請用正常的方式關機。
  • In the classroom kitchen, the chef walks. It is a count of beats, not a race.玩教室廚房的時候，廚師用走的。這是在數拍子，不是比賽跑。
  • Use a school or family computer only with permission, and do not change its settings.用學校或家裡的電腦要先得到同意，也不要更改設定。

  • Four desks in a row, each with a sheet of paper排成一排的四張桌子，每張桌上一張紙
  • One marker, which only the chef may hold一枝麥克筆，只有廚師可以拿
  • A sentence of 12 words on the board, for example: The quick brown fox jumps over the lazy dog near the river.黑板上一句 12 個字的英文句子，例如：The quick brown fox jumps over the lazy dog near the river.
  • A student to clap a steady beat, and one to keep count一位同學穩定地打拍子，一位負責數

Steps · 步驟

  1. One student is the chef. The job at each desk is to copy the sentence: one word on each beat. Walking from one desk to the next costs one beat, and nothing is written during it.一位同學當廚師。每張桌子的工作是把那個句子抄一遍：一拍寫一個字。從一張桌子走到下一張要花一拍，這一拍什麼都不寫。
  2. Round 1: the chef finishes the whole sentence at one desk before moving on. Count the beats until all four are done. When does the last desk get its first word?第一回合：廚師在一張桌子把整句抄完，才換下一張。數一數四張都抄完要幾拍。最後一張桌子在第幾拍才寫下第一個字？
  3. Round 2: the chef writes three words at a desk, then moves on, around and around. Count again.第二回合：廚師在一張桌子寫三個字就換下一張，一圈一圈輪下去。再數一次。
  4. Round 3: one word at each desk. How many beats this time, and how many of them were spent walking?第三回合：每張桌子只寫一個字就換。這次一共幾拍？其中有幾拍花在走路？

The counts should match the model: 51 beats, then 63, then 95, with 3, 15, and 47 beats of walking. Ask which round the students at the last desk liked best, and which round finished first. In Taiwan’s junior high Information Technology curriculum, this lesson matches the topic “System platforms”: 資 S-IV-2, whose notes list the operating system.
數出來應該和模型一樣：51 拍、63 拍、95 拍，其中走路分別是 3、15、47 拍。問問坐在最後一張桌子的同學最喜歡哪一回合，再問哪一回合最早全部做完。對照十二年國教國中「資訊科技」的學習內容，這一課對應「系統平台」主題：資 S-IV-2 系統平台之組成架構與基本運作原理（附錄的說明列有作業系統）。

Classroom Activity 2 · 課堂活動二

Check It on Your Own Computer 在自己的電腦上驗證

You need · 準備材料

  • A Windows or Mac computer一台 Windows 或 Mac 電腦
  • Paper and a pencil紙和鉛筆

Steps · 步驟

  1. On a Mac, open Activity Monitor and click CPU. On Windows, open Task Manager and select the Performance tab.Mac：打開「活動監視器」，按 CPU。Windows：打開「工作管理員」，選 Performance（效能）分頁。
  2. On a Mac, find three numbers at the bottom of the window: System, User, and Idle. Write them down. What do they add up to?Mac：在視窗最下面找到三個數字：System（系統）、User（使用者）、Idle（閒置）。把它們記下來。加起來是多少？
  3. Look at the list of what is running. Without ending anything, count roughly how many items there are. Is it more than the number of apps you opened?看看正在執行的東西的清單。什麼都不要結束，大概數一數有幾項。比你自己打開的 App 多嗎？
  4. Open one more app, wait a moment, and look at the numbers again.再多開一個 App，等一下，再看一次那些數字。

Apple explains the three numbers: System is the share of the processor used by processes that belong to macOS, User is the share used by apps you opened, and Idle is the share not being used. Apple also says that most of the time the processor uses only a small percentage of its power. So the operating system needs turns of its own, and most of the time there is plenty to go around.
Apple 對這三個數字的說明是：System 是屬於 macOS 的行程用掉的處理器比例，User 是你打開的 App 用掉的比例，Idle 是沒有在用的比例。Apple 還說，大部分時候處理器只用到一小部分的能力。也就是說，作業系統自己也要輪到；而大部分時候，處理器的時間綽綽有餘。

Sources · 資料出處

Facts on this page were checked against these sources (October 2026); the kitchen model is our own illustration, and every number is tested · 本頁的事實依下列資料查證（2026 年 10 月）；廚房模型是我們自己的示意，每一個數字都有測試

  1. An operating system is a “program that manages a computer’s resources, especially the allocation of those resources among other programs”; resources include the CPU, memory, file storage, input/output devices, and network connections; it “runs indefinitely and terminates only when the computer is turned off”; “each process is allowed to use the CPU for a limited time, which may be a fraction of a second, and then must give up control and become suspended until its next turn. Switching between processes must itself use the CPU”; virtual memory helps to prevent programs from interfering with each other; the first digital computers had no operating systems; the first were developed in the mid-1950s; CTSS and the Dartmouth College Basic System; UNIX, Linux, iOS, and Android; real-time systems for assembly lines, aircraft, and home appliances作業系統是「管理電腦資源的程式，特別是把這些資源分配給其他程式」；資源包括 CPU、記憶體、檔案儲存、輸入輸出裝置與網路連線；它「一直執行，只有電腦關機時才結束」；「每個行程只能使用 CPU 一段有限的時間（可能是幾分之一秒），然後必須交出控制權、暫停到下一次輪到。在行程之間切換本身也必須用到 CPU」；虛擬記憶體有助於防止程式互相干擾；最早的數位電腦沒有作業系統；最早的作業系統出現在 1950 年代中期；CTSS 與達特茅斯學院 BASIC 系統；UNIX、Linux、iOS、Android；用於生產線、飛機、家電的即時系統David Hemmendinger, “operating system,” Encyclopaedia Britannica ↗
